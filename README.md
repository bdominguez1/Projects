Hospital Database System (SQL Project)
Overview

This project implements a relational database system designed to manage core hospital operations such as patient records, staff information, appointments, and medical data. The database was developed as part of a Database Systems course and demonstrates practical SQL concepts including schema design, data population, complex queries, and database integrity.

The system models real-world hospital workflows and provides a structured way to store, retrieve, and analyze hospital data.
